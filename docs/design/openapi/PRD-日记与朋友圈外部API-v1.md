# 日记与朋友圈外部 API

## 目标与决定

持有 LXM 账号 API Key 的外部客户端，可以浏览该账号在日记和朋友圈页面看到的内容，也可以点赞、评论、回复和同步阅读状态。用户在两个入口之间切换时，看到同一份记录。

| 编号 | 已确认决定 | 来源 |
|---|---|---|
| D1 | 复用现有 API Key。升级前已签发且仍有效的 Key 自动获得两组能力，用户无需换 Key 或单独授权。 | 本轮用户明确决定 |
| D2 | 以现有 H5 用户页面为功能范围。朋友圈包含图片、全文、评论、回复、点赞及撤赞。日记包含整篇阅读、选日、翻篇及已读。 | 本轮原始请求及获准的开发方案 |
| D3 | 本期在 Open v1 提供数据和操作。图片预览、日历、信纸和翻页由调用方呈现，复用现有消息与音乐能力。 | 本轮获准方案及现行页面契约 |

## 功能与验收

以下均为 ✅ 已确认范围。验收描述指的是用户可观察的结果。

| 需求 | 操作与边界 | 验收 |
|---|---|---|
| F1 账号访问 | 每次按已验证的 Key 确定账号。无效 Key、已替换的 Key 或被封禁账号无法访问。 | AC1 已签发的有效 Key 可以直接访问两组接口；账号 B 无法读取 A 的日记或私有评论，也无法改写 A 的已读状态。 |
| F2 浏览动态 | 读取主页资料、按页浏览、刷新单帖，按发布顺序显示正文、话题、图片和计数。帖子必须已到发布时间、生成就绪、可见且位于当前历史窗口。 | AC2 多图地址可在外部客户端依次打开；同一发布时间的帖子跨页可取全；直接访问不可见帖、按旧 ID 写入或定位不可见回复均失败或无结果。 |
| F3 点赞与评论 | 点赞可撤销；用户能发表普通评论，也可点击小梦的回复继续说。回复标记沿用 H5 单条评论机制。两个入口共用内容检查、每人同帖 30 秒频控和 200 字限制。 | AC3 外部点赞或撤赞后 H5 读取相同状态。用同一请求键重试成功评论只产生同一评论及一次待回复记录；改变请求内容返回冲突。 |
| F4 小梦回复与提醒 | 小梦沿用现有异步任务回复。评论与回复仅对本人可见。新帖推送、角标、进入页面、帖子阅读、回复已读各有对应动作。 | AC4 回复生成后可从 H5 和外部查看。角标及进入时的定位指向可见的未读回复；显式上报已读后两端同步。仅轮询不会清未读。 |
| F5 日记浏览 | 列表按创建时间倒序，正文保留换行。日历优先用覆盖的北京日期，旧数据按 H5 规则用创建时间回退。七日栏、月历、同日首篇、前后篇及回到最新一篇均由列表驱动。 | AC5 同日多篇均可翻阅；今天无日记时回到最新已有篇。分页取全后才能显示所选日期为空；加载失败可重试并保留当前篇。全库为空时区分新用户与已有关系的文案。 |
| F6 已读与页面展示 | 拉取列表、分页、月历或预取保持日记原有状态；正文实际呈现后才提交已读。H5 帖子阅读参考门槛为一半可见连续 3 秒，回复可见 60% 后上报。 | AC6 预取后从另一端仍看到未读。显式阅读后两端均已读，多次提交结果一致。 |

## 调用流程与依赖

1. 打开朋友圈时读取主页、帖子与角标。真正进入后上报进入动作。如有未读回复，可用返回的帖子 ID 和评论 ID 打开对应位置。后台查询只取数据。
2. 点赞立即取得结果。发评论时调用方为本次操作保存一个请求键；收到超时用原键和原内容重试。收到小梦的回复后，用户可以阅读或再次回复。新帖事件流断开后，重新读取角标和列表。
3. 阅读日记时先打开首篇，按需补齐分页。选中空日期不会生成日记。正文可见后提交已读；外部客户端可按现有资源规则绘制信纸，并复用音乐目录及聊天入口。

数据来自现有用户、帖子、点赞、评论、日记和关系记录。外部可见评论数沿用页面展示口径，可能大于本人能展开的评论条数。产品范围覆盖读取及页面互动；日记生成、后台内容管理、公开分享私有记录均在本轮范围之外。模型生成失败、延迟及重试沿用既有评论任务。当前月历查找可能需要翻完所有分页；独立月历查询为后续优化建议，本期使用两个日记端点。

技术交付以[外部接口契约](../../contract/current/openapi/api.md#feed-diary-openapi)为准，H5 行为依据[日记页面](../../contract/current/diary/api.md)与[朋友圈](../../contract/current/life-feed/api.md)。对现有 Key 的权限扩展由 D1 明确覆盖，没有待定授权项。
