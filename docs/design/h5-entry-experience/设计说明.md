## 1. 已确认范围

- 每次重新打开网站显示开场层；同一文档中的站内切页和返回不再显示。
- 主按钮「开启并进入」同时发起音乐播放和倾斜授权；保留「直接进入」。
- 拒绝权限、缺少设备能力或跳过均不阻塞正常使用；两项能力独立处理。
- 麦克风保持现有通话流程，只在发起通话时申请。
- 效果应平缓、连贯，沿用当前主页夜景、人物与紫色视觉，不新增独立 HTML 导航。

生命周期设计建议：刷新或新标签创建新文档时重新显示；同文档 history 导航、后台切回、BFCache 恢复不重复显示。是否已完成本次开场由文档级状态持有，不能用持久化的“已访问”标记跳过下一次打开。

## 2. 方案与取舍

| 方案 | 取舍 | 结论 |
|---|---|---|
| 独立欢迎页面再跳转主页 | 页面分明，但文档更换不利于保持首次点击和播放器状态，容易产生二次加载 | 不采用 |
| 同文档全屏开场层，延续现有加载画面 | 可让加载、选择、主页共用背景；播放器和方向授权留在同一文档 | 本次采用，用户已确认 |
| 自动尝试后用音乐提示补救 | 首屏直接，但首次有声体验和倾斜授权分散 | 保留为进入后的恢复入口，不作为本次开场方案 |

## 3. 用户流程

1. **打开文档**：先显示原来的完整加载画面（夜景、光效、头像、原文案、底部进度条与百分比），同时挂载目标路由与必要资源。底部音乐 / 倾斜操作区此时隐藏且不可交互；选择前不自动出声、不启动方向监听。
2. **准备完成**：沿用原加载节奏，进度完成并短暂保持后，仅底部进度区域约550ms平缓淡出，原位置交叉淡入音乐 / 倾斜操作区。背景、头像光圈、昵称、昵称下文案及蒙版保持相同 DOM、样式与位置。过渡结束才启用「开启并进入」和「直接进入」，不再整屏换画面。
3. **点击主按钮**：在同一次原生点击内直接发起音频播放 / 音频上下文恢复与方向权限申请，不先等待网络、动画或另一个权限 Promise。
4. **需要方向授权**：需要提示时由浏览器显示原生方向权限框（并非每次点击都弹）；我们的开场已说明用途，不额外叠加自制确认框。系统框显示期间保持原加载背景、文案与蒙版，底层页面仍隔离并保持约8px模糊，不提前揭示主页。已允许、已拒绝及不支持时按实际结果处理，无需等待用户再次选择。
5. **进入**：用户点允许或拒绝后，再用约 800ms 退去模糊与遮罩；拒绝也正常进入，不以权限成功或音乐下载完成作为通行条件。真实申请异常或系统框关闭时应有降级出口，不能永久卡住；正式接入核对目标浏览器的返回行为，迟到结果只属于本次有效请求。
6. **直接进入**：本次不播放音乐、不发起方向授权、不使用旧倾斜开启标记偷偷启动监听；随后仍可主动开启。
7. **站内导航**：开场标记留在全局文档层，不随 Home 页面卸载重建，不重复遮挡，不重启音乐。

音乐播放与方向授权仍在原始点击内同时发起；仅视觉转场等待方向权限结果。用户未作选择时，模糊背景、遮罩和人物构图保持原状，主页不可操作；允许与拒绝共用同一条淡入路径。「直接进入」及无需弹框的路径立即开始淡出。系统框显示期间的焦点与输入由浏览器管理，页面不能自绘替代或强行关闭它。

## 5. 过渡与动效

| 阶段 | 建议时长 | 表现 |
|---|---:|---|
| 底部进度 → 操作区 | 完成保持500ms，底部交叉淡入淡出550ms | 背景、头像、昵称、昵称下文案与原蒙版不改变；底部切换结束后按钮可交互 |
| 主按钮就绪 | 呼吸2.6秒、流光3.6秒、渐变单程5.2秒 | 就绪后开始循环，首秒内出现流光；文字和按钮尺寸稳定；禁用及减少动态时停止循环 |
| 主按钮按下 | 即时 | 锁定本次选择并发起两项调用；防止重复点击；不等转场结束再调用受手势限制的 API |
| 等待授权选择 | 由用户决定 | 保持模糊和遮罩；按钮显示「等待授权…」；不提前转场，不用定时器代替允许或拒绝 |
| 开场 → 主页 | 800ms | 允许或拒绝后开始；渐变遮罩与文案降低透明度，底层页面模糊由约 8px 平缓减至 0；原加载元素不移动或缩放；不整屏上滑、不突然锐化 |
| 主页内容显现 | 各约650ms，轻微错开 | 顶部信息、快捷区、卡片、聊天入口依次显出，位移最多7px；与遮罩淡出重叠，避免先黑屏再出现 |
| 音乐进入 | 约1.2s，可用时 | 复用现有淡入淡出能力及设置；实际开始播放后再淡入，不延后播放调用；能力不支持时不伪装有淡入 |
| 首次方向基准 | 收到首个有效事件后 | 以当前姿态为零点；沿用既有平滑与位移上限，不因授权后第一个绝对角度突然跳动 |
| 系统减少动态 | 约120ms | 仅短淡入淡出，无位移、缩放、粒子或主动倾斜；音乐选择独立 |

保留原加载节奏，不额外叠加倒计时或整屏闪光。进度沿用原随时间推进、准备完成后收至100%的视觉进度，不是文件下载字节测量；页面 / 音乐准备尚未结算时不提前完成，8秒仍可按原有降级出口继续。慢网/资源失败不能形成永久遮挡。授权等待不展示进度，模糊背景与原允许 / 拒绝后淡入流程保持。

## 6. 状态与边界

| 情况 | 音乐 | 倾斜 | 页面 |
|---|---|---|---|
| 主按钮，两项成功 | 按真实播放状态显示 | 首个有效方向后生效 | 平缓进入 |
| 方向拒绝 | 可继续播放 | 保持关闭，可在设置主动重试 | 正常进入；必要时仅一次轻提示 |
| 已有拒绝决定 | 独立处理 | 不反复强弹权限，提供设置说明 | 正常进入 |
| 无传感器 / 不安全上下文 | 独立处理 | 能力降级，不误报已开启 | 正常进入 |
| 音乐被拦截 / 加载失败 | 不显示虚假的播放中；提供 BGM 恢复入口 | 按真实方向授权与事件处理 | 正常进入 |
| 直接进入 | 本次暂停 | 本次不申请、不监听 | 相同淡出路径 |
| 系统减少动态 / 主页动效关闭 | 音乐独立处理 | 遵守原动效约束，不绕过关闭决定 | 无位移的短过渡 |
| 重复点击、路由变化、退出或后台 | 当前有效所有者处理 | 遵守原取消/失效规则 | 迟到结果不写入已失效页面 |

偏好建议：开场选择只决定本次体验，不暗改“下次打开自动播放”、渐变或系统设置；主按钮是本次明确播放与倾斜意图，可以覆盖本次暂停状态。对于旧“关闭音乐”语义，正式接入必须沿用已有显式主页开启路径，不借任意导航重开。倾斜本次选择沿用现有标签会话与关闭覆盖语义，不新增跨账号上报或服务器设置。

直接进入非主页地址时也只显示这一次全局开场；选择后揭示原目标路由，不强制跳主页。原型仅用主页作视觉载体。Login 路由保持已有音频阻断，不能为开场绕过；此时倾斜只在可用主页环境运行，选择不改变登录/访客权限边界。
