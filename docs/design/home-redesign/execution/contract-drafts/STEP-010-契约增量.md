## 1. 本阶段摘要

登录用户更多互动打开动态设置；访客走现有共享登录，成功只刷新登录数据，不自动打开原动作或申请权限。主页动态选择与实际运行状态分开显示，系统减少动态优先。

## 2. 契约变更

- 数据与存储：新增 localStorage lxm_home_motion_enabled：0=关闭，1=开启，无保存默认开；初始化首次可能运行动效之前读取。当前浏览器跨刷新／重访／账号保持，不同步设备。读取异常默认本次开并提示，写入失败仅本次生效，不伪装保存成功。
- 接口、事件、配置与兼容：保留原 Session key 与登录语义；新 UI 无后端接口；关闭动态停止动作和方向监听，开启不自动请求传感器权限。
- 服务端接口／协议新增、删除：无。
- 实现位置：frontend/static/js/home-scene.js；frontend/pages/index.html::handleHomeQuickAction；frontend/static/css/home-scene.css。

## 3. 对现有正式契约的影响

更新首页场景／加载／交互的对应语义；保留当前开放页登录、端点和数据字段，不新增重复业务入口。
