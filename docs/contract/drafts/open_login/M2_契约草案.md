# M2 临时契约：四个开放页面访客态

> 状态：STEP-003～STEP-006 已实现并专项/浏览器验证（2026-08-02）。  
> 性质：非权威历史快照；有效条款已整合至正式 H5 App / Life Feed 契约。

## 页面状态矩阵

| 页面 | 无 token | 背景请求 401 | 主动私有交互 | 弹窗认证成功 |
|---|---|---|---|---|
| Index | 默认头像/状态、`故事从今天开始`、关系 `0 / 200`、日记锁定占位、隐藏未读；仅加载公共 Feed | 静默清 token 并保持访客态 | 五个快捷入口、关系和日记入口弹窗 | 当前页私有首页数据与未读信息各恢复一次 |
| Feed | 只请求公共 Header/List；不 enter、不连 SSE、不启动观察器、不处理 focus | 清理 SSE/观察器及已渲染私有评论，匿名 Header/List 各重新请求一次 | 点赞/评论在任何 UI 或请求变更前门禁 | 恢复 enter、badge、私有列表、SSE/观察器各一次，不重放之前写操作 |
| Settings | 默认资料；私有标题/设置卡隐藏；About 可独立加载公共 persona | 私有区域静默隐藏，About 保留或独立重试 | 登录按钮弹窗；登录态设置操作保持原行为 | 当前页关系、状态与设置各恢复一次 |
| Chat | 仅渲染访客壳；不读时间线/未读/草稿，不发模型请求 | 初始化 401 静默访客化 | 发送、Enter、重试、记忆入口均先门禁；Feed 仍公开 | 恢复时间线/未读/草稿一次，保留输入但不自动发送 |

## 一致性约束

- 开放页允许停留不等于其私有接口匿名开放。
- 背景 401 不打断浏览；主动交互 401 才显示登录弹窗。
- 主动请求 401 必须回滚幽灵消息、临时点赞/评论等 UI，并保留用户可恢复输入。
- 登录/注册成功只恢复页面数据与资源一次，不自动重放触发登录的写操作（UD-02=A、UD-03=A）。
- Feed 访客响应及 DOM 均不得残留当前用户评论或 `user_liked`。
