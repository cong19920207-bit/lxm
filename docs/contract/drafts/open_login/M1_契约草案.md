# M1 临时契约：可选鉴权与共享登录弹窗

> 状态：STEP-001、STEP-002 已实现并专项验证（2026-08-02）。  
> 性质：非权威历史快照；有效条款已整合至正式 Life Feed / H5 App 契约。

## 匿名接口白名单

| 方法 | 路径 | 无 Authorization 头 | 有效 Bearer | Authorization 存在但无效 |
|---|---|---|---|---|
| GET | `/api/feed/list` | 200，公共 Feed | 200，保留登录用户语义 | 401 |
| GET | `/api/feed/config/header` | 200，公共 Header | 200 | 401 |
| GET | `/api/app/persona-background` | 200，公共人格背景 | 200 | 401 |

“无效”包括空值、非 Bearer scheme、空 Bearer、伪造/过期 token 和封禁用户。只有完全缺少 `Authorization` 头才进入匿名分支。

## Feed 条件字段与查询隔离

- 匿名条目不包含 `user_liked`、`comments` 或其他用户绑定字段。
- 匿名服务分支不执行按当前用户查询点赞或评论的 SQL。
- 公共可见性、分页游标、展示点赞/评论计数、发布时间口径及既有 `actual_publish_time` 幂等懒写回保持不变。
- `/api/feed/enter`、badge、events、like、comment、read 及其他未列出的接口继续强制登录。

## 共享登录弹窗

- 默认登录面板，可切换注册和找回密码；重复打开复用单例。
- 登录成功：保存 token、关闭弹窗、在原开放页执行成功回调一次。
- 弹窗注册成功（UD-01=A）：直接保存注册响应 token、关闭弹窗并回调一次。
- 独立 `login.html` 注册成功：仍提示“注册成功，请登录”并回登录面板；登录成功仍去首页。
- 找回密码沿用既有接口和校验，不增加短信、邮箱或第三方身份校验。

## 401 策略

| 策略 | 使用场景 | 结果 |
|---|---|---|
| `LEGACY_LOGIN_PAGE` | 尚未显式迁移的既有调用点 | 清 token，保持原独立登录页回退 |
| `SILENT_VISITOR` | 开放页背景读取 | 清 token，页面降级为访客，不弹窗 |
| `INTERACTIVE_MODAL` | 用户主动写操作/私有交互 | 清 token，回滚本次临时 UI，当前页弹登录窗 |
| `PROTECTED_HOME_MODAL` | 受保护页初始化或中途 401 | 清理私有资源，以 `replace` 回首页，写入并消费一次性弹窗信号 |

策略是调用点显式选择；未改变认证 API 请求/响应契约。
