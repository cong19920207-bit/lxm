# M3 临时契约：受保护页面统一回退

> 状态：STEP-007 已实现并专项/浏览器验证（2026-08-02）。  
> 性质：非权威历史快照；有效条款已整合至正式 H5 App 契约。

## 页面与接口

| 页面 | 直接无 token | 初始化中收到 401 | 登录后 |
|---|---|---|---|
| Diary | 私有请求前回首页 | 停止观察器/私有初始化，回首页 | 留在首页并恢复首页登录态，不自动返回 Diary |
| Memory | 渲染器/动画/私有请求前回首页 | 停止 RAF、定时器、渲染器和连接层，回首页 | 留在首页，不使用 return URL |
| Relationship | 私有请求前回首页 | 停止增长观察器/私有初始化，回首页 | 留在首页，不自动返回 Relationship |

- 回退使用一次性页间信号；首页消费后立即清理。
- 同页并发 401 只允许一次导航、一次自动弹窗；刷新、关闭弹窗或后退不形成循环。
- 三模块后端 GET 仍为强鉴权：无 token 均返回 401。
- 未新增匿名占位 API、分享预览、return URL 或登录后自动回跳。
