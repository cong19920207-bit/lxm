### [RP-006] 在后台展示 Step6 提取的非向量用户信息

**用户反馈**：Step6 涉及的用户信息较多，目前后台主要展示部分向量信息，昵称、姓名、后续行动计划等非向量信息缺少展示。

**用户需求**：在后台补充展示这些非向量用户信息，至少覆盖昵称、姓名和后续行动计划；其他应展示的信息在细化时一并核对。

**待细化事项**：完整字段范围及各自的数据来源；后台展示入口与组织方式；展示当前值还是历史变化，以及空值和未提取时的提示。是否支持编辑或操作后续行动计划，另行确认。
